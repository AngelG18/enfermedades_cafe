# enfermedades_cafe
#Sistema de Diagnóstico de Enfermedades en Café

## Descripción
Agrodetect es una plataforma web inteligente diseñada para la detección automatizada de enfermedades en hojas de café (Roya, Cercospora, Phoma, etc.). Utiliza un modelo de Deep Learning (CNN) para el diagnóstico y la API de Groq (Llama 3) para proporcionar recomendaciones técnicas agronómicas personalizadas.

## Tecnologías Empleadas
- **Frontend/Backend:** Python con [Streamlit](https://streamlit.io/)[cite: 2]
- **IA/Deep Learning:** [TensorFlow/Keras](https://www.tensorflow.org/) (MobileNetV2)
- **Generación de Recomendaciones:** [Groq API](https://groq.com/) (modelo Llama 3)
- **Despliegue:** [Google Colab](https://colab.research.google.com/) con [Localtunnel](https://localtunnel.github.io/www/)[cite: 2]
